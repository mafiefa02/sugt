Text field for SUGT internal forms.

```jsx
<Input placeholder="Cari sekolah…" />
<Input as="textarea" placeholder="Apa yang diajarkan" />
<Input aria-invalid="true" defaultValue="—" />
```

`as="textarea"` for prose fields (Session Record). `aria-invalid="true"` shows the destructive-red error state. h-32px, rounded corners, 3px focus ring at `--ring`.
